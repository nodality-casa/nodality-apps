# Node Guard

Part of Nodality. Makes sure Home Assistant starts again after a restart, and that only one of your two instances
runs your home. It also keeps Nodality's scheduled checks running if the Nodality app itself stops. Nodality sets
this app up when you pair your instances. The only option is how long Core may stay stopped before this app acts.
