# Nodality apps

Home Assistant apps for Nodality: failover for Home Assistant.

To install, add this repository in Home Assistant (Settings > Apps > App store > Repositories) using the address
`https://github.com/nodality-casa/nodality-apps`.

**Status: placeholder for testing the distribution path. Not a release.**

This repository holds only the app manifests, icons, licence and third-party notices. The app images are published
to the Nodality container registry (`ghcr.io/nodality-casa`).
