# Nodality

Keeps your home running on a second Home Assistant. This app connects this Home Assistant to the Nodality Cloud
Console over an encrypted connection it opens itself (nothing is opened to the internet). Register it from the
Nodality panel in the sidebar with the code the panel shows, then complete set-up in the Cloud Console.

Nodality is independent and is not made, endorsed or certified by the Home Assistant project, Nabu Casa or the
Open Home Foundation. Third-party notices and the source offer are in the image under `/licenses`.
